1Definition

The Bradley-Terry model is a probability model for pairwise comparisons. It assumes every item i has a single latent strength parameter βi, and the probability that i beats j depends only on the difference between their strengths, passed through a logistic function: P(i ≻ j) = σ(βi − βj). Given a pile of recorded comparisons — who beat whom, how often — you recover all the β's at once by maximum likelihood, producing a single global ranking from purely local, incomplete head-to-head data.

Two things make it central to modern ML. First, it's the statistical foundation of RLHF reward models: "human preferred response A over B" is exactly a pairwise comparison, and the standard reward-model loss is the Bradley-Terry negative log-likelihood. Second, it's what LLM arenas actually fit — Elo processes matches sequentially and is therefore order-dependent, whereas Bradley-Terry fits all battles simultaneously and gives one order-independent answer plus proper confidence intervals.

2Analogy

Imagine a office coffee taste-test where nobody ever rates a coffee out of ten — every participant only ever says "I like this cup better than that one." You end up with a heap of scattered verdicts: Ethiopian beat Colombian twice, Colombian beat Sumatran three times, Sumatran beat Ethiopian once. No coffee has a score, no two people tried the same set, and the comparisons even contradict each other.

Bradley-Terry is the statistician who walks in and says: suppose each coffee has one hidden "tastiness" number, and the chance one wins a matchup depends only on the gap between those numbers. Then it asks: which set of hidden numbers would make the verdicts we actually observed as likely as possible? Out come consistent scores, from data that never contained a single score — and the contradictions get absorbed as noise rather than breaking the ranking.

4History → Current → Future

1929
Ernst Zermelo (better known for set theory) derives the model and its iterative MLE algorithm to rank chess players from incomplete tournament results — decades before it was rediscovered.
1952
Ralph Bradley and Milton Terry publish the paper that gives the model its name, framing it as the standard method for analyzing paired-comparison experiments (taste tests, product preference studies).
1959–2004
Luce's choice axiom generalizes it to multi-way choice (Plackett-Luce for full rankings); Elo adapts the same logistic form into an online, sequentially-updated approximation for chess; Hunter (2004) formalizes the MM algorithm that makes fitting fast and guaranteed to converge.
2017–2022
Christiano et al. use it as the likelihood for learning reward models from human preferences; InstructGPT and ChatGPT make that the default RLHF recipe, putting Bradley-Terry inside essentially every aligned LLM.
Current
LMArena and similar leaderboards report Bradley-Terry fits with bootstrapped confidence intervals rather than raw Elo, precisely for order-independence. DPO derives its loss directly from the Bradley-Terry likelihood — it's the same model, with the implicit reward written in terms of policy log-ratios. Extensions add ties (Davidson), home advantage, and per-rater effects.
Future
Work is moving beyond the model's core assumption that one scalar per item suffices: intransitive preferences (rock-paper-scissors dynamics), heterogeneous and pluralistic raters, style-controlled fits that separate substance from verbosity/formatting, and preference models with uncertainty for active data collection.

5Example

Three models. A beat B 7 of 10 times; B beat C 7 of 10 times; A and C never played.

  • From A vs B: σ(βA − βB) = 0.7 → βA − βB = ln(0.7/0.3) ≈ 0.85
  • From B vs C: likewise βB − βC ≈ 0.85
  • Fixing βB = 0 (strengths are only defined up to a shift): βA ≈ 0.85, βC ≈ −0.85
  • Therefore P(A beats C) = σ(0.85 − (−0.85)) = σ(1.70) ≈ 0.85

That last line is the whole point: the model predicts an 85% win rate for a matchup that was never played, by chaining through their common opponent. This is what lets an arena rank hundreds of models without any of them playing a full round-robin — and it's also the model's main assumption laid bare, since it forces transitivity: it cannot represent "A beats B, B beats C, C beats A" rock-paper-scissors structure.

6Use cases

  • RLHF reward models: the reward-model training loss is literally the Bradley-Terry negative log-likelihood over (chosen, rejected) response pairs — the single most important use in modern ML.
  • DPO and preference optimization: DPO's loss is derived from this likelihood, with the reward re-expressed as a policy/reference log-ratio.
  • LLM leaderboards: LMArena/Chatbot Arena fits Bradley-Terry over millions of anonymous human votes, with bootstrapped CIs.
  • Sports & esports ranking: its original home — ranking teams and players from incomplete schedules where not everyone plays everyone.
  • Product & UX research: A/B preference tests, taste tests, and conjoint-style studies where people compare rather than score.
  • Search & recommender ranking: learning-to-rank from pairwise click/preference judgments (RankNet uses the same logistic pairwise likelihood).
  • Evaluation with LLM judges: aggregating thousands of "which response is better" judgments into one score per system.

7Math & Python

The model, in strength-difference (logit) form:

P(i ≻ j) = σ(βi − βj) = eβi / (eβi + eβj)

Writing pi = eβi gives the classic "ratio" form P(i ≻ j) = pi/(pi + pj). With wij = times i beat j, the log-likelihood over all pairs is:

ℓ(β) = Σi,j wij · log σ(βi − βj)

Two notes that matter in interviews. (1) Identifiability: only differences are determined, so you must anchor the scale (fix β₁ = 0, or center them) — otherwise adding a constant to every β gives an identical likelihood. (2) Existence: the MLE is finite only if the comparison graph is strongly connected; if some item never loses (or a group never plays another group), its strength runs to ±∞ and you need regularization. The standard fitting method is the MM (minorize-maximize) algorithm, which is monotone and needs no step size:

pi ← Wi ⁄ Σj≠i [ nij / (pi + pj) ]

where Wi is i's total wins and nij the games between i and j — renormalizing after each sweep.

import numpy as np

def fit_bradley_terry(W, iters=200, tol=1e-10):
    """W[i][j] = times i beat j.  Returns log-strengths beta."""
    n = W.shape[0]
    N = W + W.T                    # games played between each pair
    wins = W.sum(axis=1)           # total wins per item
    p = np.ones(n)                 # p = exp(beta), all equal to start

    for _ in range(iters):
        p_old = p.copy()
        for i in range(n):
            denom = sum(N[i, j] / (p[i] + p[j])
                        for j in range(n) if j != i)
            p[i] = wins[i] / denom
        p /= p.prod() ** (1 / n)   # anchor: geometric mean = 1
        if np.max(np.abs(p - p_old)) < tol:
            break
    return np.log(p)

W = np.array([[0, 7, 0],           # A beat B 7 times
              [3, 0, 7],           # B beat A 3, beat C 7
              [0, 3, 0]], float)   # C beat B 3 times

beta = fit_bradley_terry(W)
beta = beta - beta[1]              # anchor at B = 0 for readability
print(beta.round(3))               # [ 0.847  0.    -0.847]

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def fit_bradley_terry(W, iters=200, tol=1e-10):
    """W[i][j] = number of times i beat j.  Returns strengths beta (centered).
    Uses the MM algorithm (Zermelo/Hunter): monotone, no learning rate."""
    n = W.shape[0]
    N = W + W.T                      # total games between each pair
    wins = W.sum(axis=1)             # total wins per item
    p = np.ones(n)                   # positive-scale strengths, p = exp(beta)

    for _ in range(iters):
        p_old = p.copy()
        for i in range(n):
            denom = sum(N[i, j] / (p[i] + p[j]) for j in range(n) if j != i)
            p[i] = wins[i] / denom if denom > 0 else p[i]
        p /= p.prod() ** (1 / n)     # anchor the scale (geometric mean = 1)
        if np.max(np.abs(p - p_old)) < tol:
            break
    return np.log(p)                 # back to log-strengths (beta)

# --- The worked example: A beat B 7/10, B beat C 7/10, A never played C ----
#        A   B   C
W = np.array([[0,  7,  0],       # A beat B 7 times
              [3,  0,  7],       # B beat A 3, beat C 7
              [0,  3,  0]], float)

beta = fit_bradley_terry(W)
beta = beta - beta[1]                       # anchor at B = 0 for readability
print("strengths (A, B, C):", beta.round(3))          # ~ [0.85, 0.0, -0.85]
print("P(A beats C), never played:",
      round(sigmoid(beta[0] - beta[2]), 3))           # ~ 0.847

# --- Same model as an RLHF reward-model loss ------------------------------
# Each row is one human preference: reward of chosen vs rejected response.
r_chosen  = np.array([2.4, 1.9, 3.1, 0.8])
r_rejected = np.array([1.1, 2.2, 0.4, 0.5])
bt_loss = -np.mean(np.log(sigmoid(r_chosen - r_rejected)))
print("Bradley-Terry / reward-model loss:", round(bt_loss, 4))
# Identical formula: preference likelihood == reward model training objective.
