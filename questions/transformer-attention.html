What is the attention mechanism in Transformers?

Deep Learning · transformers · attention · LLMs

1Definition

Attention is a mechanism that lets a model, when processing one token, look at every other token in the sequence and decide — with learned, continuous weights — how much each one matters for understanding the current token. Each token emits a query ("what am I looking for?"), a key ("what do I contain?"), and a value ("what information do I pass along?"). The output for a token is a weighted average of all values, where the weights come from how well its query matches each key. Self-attention is this operation applied within a single sequence, and it is the core building block of the Transformer architecture behind GPT, Claude, BERT, and modern LLMs.

2Analogy

Imagine a meeting room where every word of a sentence is a person. When it's your turn to speak (be processed), you don't listen to everyone equally — you hold up a card saying what you need (query), everyone else wears a badge saying what they know (key), and you turn your ears toward the people whose badges best match your card. What you actually take away from each person is what they say (value), blended in proportion to how much you attended to them. The word "it" holds up a card reading "I need my referent" — and the person wearing the "ball" badge gets most of its attention.

4History → Current → Future

2014
Bahdanau et al. add attention to RNN encoder–decoders so machine translation can "look back" at source words instead of squeezing everything into one fixed vector.
2017
"Attention Is All You Need" (Vaswani et al.) removes recurrence entirely: the Transformer is built purely from self-attention + feed-forward layers, unlocking massive parallelism on GPUs.
2018–2020
BERT (bidirectional attention) and GPT (causal/masked attention) show that pre-trained Transformers transfer to nearly every NLP task; scaling laws emerge.
Current
All frontier LLMs are attention-based. Engineering focuses on taming its O(n²) cost: FlashAttention (IO-aware kernels), grouped-query & multi-query attention, sliding-window and sparse attention, KV-cache compression — enabling million-token contexts.
Future
Sub-quadratic challengers (state-space models like Mamba, linear attention, hybrid architectures) aim to keep attention's quality at far lower cost; expect hybrids where a few full-attention layers are mixed with cheap sequence-mixing layers.

5Example

Sentence: "The robot picked up the ball because it was red."

To interpret "it", the model must resolve what "it" refers to. In self-attention, the query of "it" matches the keys of "ball" and "robot"; because "red" describes objects, not robots, the trained weights push most attention onto "ball". The output vector for "it" then becomes mostly a blend of "ball"'s value — the model has effectively performed coreference resolution in one matrix multiply. (Try clicking "it" in the visualization above.)

6Use cases

  • Large language models (Claude, GPT): every generated token attends over the whole prompt — this is what makes long-context reasoning possible.
  • Machine translation & summarization: cross-attention lets the decoder consult the source text while writing the output.
  • Vision Transformers (ViT): image patches attend to each other, replacing convolutions for classification and detection.
  • Speech & audio (Whisper): attention aligns audio frames with output text.
  • Biology (AlphaFold): attention over amino-acid pairs helps predict 3-D protein structure.
  • Recommendation systems: attention over a user's interaction history weighs which past behavior predicts the next click.

7Math & Python

Attention(Q, K, V) = softmax(Q KT / √dk) V

Q = queries, K = keys, V = values (each is the token matrix times a learned projection); dk is the key dimension. Dividing by √dk keeps dot products in a range where softmax has healthy gradients — exactly the "temperature" you dragged above.

# Scaled dot-product self-attention in plain NumPy
import numpy as np

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)      # numerical stability
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def self_attention(X, Wq, Wk, Wv):
    """X: (seq_len, d_model). Wq/Wk/Wv: learned (d_model, d_k) projections."""
    Q, K, V = X @ Wq, X @ Wk, X @ Wv             # project tokens
    scores = Q @ K.T / np.sqrt(K.shape[-1])      # (seq_len, seq_len) affinities
    weights = softmax(scores, axis=-1)           # each row sums to 1
    return weights @ V, weights                  # blended values + attn map

rng = np.random.default_rng(0)
d_model, d_k, seq_len = 16, 8, 5
X = rng.normal(size=(seq_len, d_model))          # 5 token embeddings
Wq, Wk, Wv = (rng.normal(size=(d_model, d_k)) for _ in range(3))

out, attn = self_attention(X, Wq, Wk, Wv)
print(attn.round(2))    # rows = "who each token attends to"
print(attn.sum(axis=1)) # -> all 1.0
